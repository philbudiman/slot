Slot+

A Game Boy-centric frontend for the Anbernic RG SP, based on Brandon T. Kowalski's original Slot. Slot+ keeps its cartridge-inspired design and adds Wi-Fi, browser file transfer, on-device updates, and independent maintenance.

Installing

  1. Install BaseOS or AGS-102 on SD1

    BaseOS is recommended for new installs. Current releases recognize Slot's standard frontend layout, which Slot+ continues to use; no custom launcher layer is needed. AGS-102 remains supported.

    Write the OS image to SD1 with a tool such as Raspberry Pi Imager.

  2. Download the Slot+ release

    Get the latest H700 -h700.zip archive.

  3. Prepare SD2

    Format the second card as FAT32 or exFAT with the Master Boot Record (MBR) partition scheme. Extract the archive and copy the contents of its release directory to the card root.

    The card should contain BIOS/, Games/, Labels/, and System/. The frontend executable remains System/slot.

  4. Add your games

    Put ROMs in Games/GBA, Games/GBC, or Games/GB. Optional labels go in the matching Labels/ folder; optional BIOS files go in BIOS/. ROMs and BIOS files are not included.

  5. Boot Slot+

    Insert the card into the SD slot labeled SD2 and start the handheld.

    Questions and contributions are welcome in the Slot+ repository.

Use the on-device updater from MENU → About → Check for updates, or follow the manual update guide.

User guide

  1. Browse the Carousel

    Left and Right to flip through games on the shelf.
    L1 and R1 to switch platforms.

  2. Insert and Play

    Tapping A loads the last save state.
    Holding A starts the game fresh.

  3. Ejecting a Game

    Hold MENU to eject the cart.
    On exit, Slot+ creates a save state.

  4. Save States

    SELECT + R1 creates a save state.
    SELECT + L1 loads the most recent.
    Double tap MENU to open the save state switcher.

  5. Fast-Forward and Rewind

    Hold R2 to fast-forward, or double tap to lock it on.
    Hold L2 to go back in time.

  6. Lid Detection

    Closing the lid writes a save state and turns off the display. Open it again and you're back in the game. Leave it shut for three minutes and Slot+ powers off. It will resume with that save state on the next boot.

Anticipated Questions Answered

Will Slot+ run anything other than GBA?
Yes. You can bring your GB and GBC carts to the party.
This is almost perfect but needs more systems. Will you add them?
The system list is intentionally focused, following the design of the original Slot.
Does Slot+ allow Bluetooth headphones?
No. Use the headphone jack.
How do I add cart labels?
Drop a .png into the Labels/ folder for that platform, named after the ROM. For example, Labels/GBA/Metroid Fusion.png matches Games/GBA/Metroid Fusion.gba.
Do I have to craft them by hand?
The original Slot Cart Studio can help create them.
Where do games go?
Each platform has its own folder under Games/.
Is there a BIOS boot animation on game start?
Yes! Drop the following files you legally obtained into BIOS/.
  • gba_bios.bin
  • gbc_bios.bin
  • gb_bios.bin
Where do the games come from?
Your own legally obtained backups.
Can I trade Pokémon with a friend?
Yes, with a second RG SP. First navigate to the game and press START to open the core selection menu. Pick gpSP.

While in game press SELECT + MENU and choose LINK. One player needs to pick HOST while the other chooses JOIN.
Which games can link?
Pokémon Ruby through LeafGreen, both Advance Wars, and a handful of wireless adapter games. All of them GBA: linking runs through gpSP, and gpSP does not run a Game Boy or Game Boy Color cart at all.

Credits

Slot+ began as a fork of Brandon T. Kowalski's original Slot and is now maintained independently at philbudiman/slot-plus. It preserves the original project's focused design and does not claim original authorship.

Emulation uses mGBA and gpSP through libretro. Current BaseOS releases recognize Slot's frontend layout, which Slot+ uses; AGS-102 remains supported.

Type is Open Sans, under the SIL Open Font License, and Nerd Fonts symbols by Ryan L. McIntyre, under MIT. The panel mask is derived from LCD3x, a public-domain shader by Gigaherz in the libretro shader collection.

The cartridge sounds are recordings made by Brandon T. Kowalski for the original Slot project.
